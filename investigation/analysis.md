# Investigation Workflow

## Objective

This document outlines the investigation process used to validate and correlate alerts generated within the Blue Team Detection Lab.

## Investigation Process

### Step 1 — Alert Detection

Alerts were generated by:

- Suricata IDS
- Cowrie Honeypot

These alerts indicated suspicious activity originating from the Kali attacker system.

---

### Step 2 — Identify Source IP

The source IP address was extracted from:

- Suricata EVE JSON logs
- Cowrie session logs

This allowed correlation across telemetry sources.

---

### Step 3 — Timestamp Correlation

Events were compared using timestamps to confirm:

- Same attacker activity
- Same session window
- Multi-layer detection

---

### Step 4 — Log Parsing

Logs were analyzed using:

- jq
- manual filtering

Example:

```bash
jq '.event_type' eve.json
